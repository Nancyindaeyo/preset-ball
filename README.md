# 预设悬浮球

SillyTavern / TauriTavern 第三方扩展。方案切换、一键开关、破限档位、聊天绑定、全局世界书快捷挂载。不限蛾摩拉，别的 Chat Completion 预设也能用。

手机 / TT iOS 底部面板为主，颜色跟酒馆当前美化走。

## 安装

1. 在酒馆扩展里用 Git 安装：`https://github.com/Nancyindaeyo/preset-ball`
2. 或把本仓库放到 `public/scripts/extensions/third-party/preset-ball`
3. 启用扩展。右下角会出现圆球。

快捷包按条目名匹配。换预设时方案快照仍可用；找不到的条目会跳过并提示。

## 开发

```bash
pnpm install
pnpm build
pnpm watch
```

产物在 `dist/`。酒馆从 `manifest.json` 的 `js` 加载。

## 用法（给第一次用的人）

1. 点「保存方案」或「另存一份」，把现在的开关（含快捷世界书）记下。
2. 点方案名字 = 立刻切换（会提示）。有没保存的改动时会问你要不要放弃。
3. 点「绑」= 这个聊天下次打开自动套用这份方案。没绑的聊天不会被改。
4. 快捷：蛾摩拉自带一键（基础需求 / 优化 / NSFW / 情感扫描 / 缄默 / 功能分区 / 蛾摩拉说）和破限档位。点箭头打开抽屉，改里面每条的开合，也能加一条、删一条、删整块。
5. 「新建一组」：每条自己开关 / 只能开一条 / 点一下开一组 / 档位（一次加一层）。备注写在名字下面，比如「一次加一层」。
6. 世界书：先「加入一本」，点一下挂全局。保存方案会记住现在挂着哪些快捷书；切到没勾这本书的方案会把它摘掉。
7. 细调：蛾摩拉按出厂文件夹。别的预设第一次会让你自己分组，之后和细调一样。
8. 顶部红字是冲突提示。只改开关、没有真的打架时不会一直标红。
