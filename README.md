# 预设悬浮球

SillyTavern / TauriTavern 第三方扩展。给蛾摩拉 2.6 做方案切换、NSFW/伦理/破限叠加、聊天绑定和全局世界书快捷挂载。

手机 / TT iOS 底部面板为主，颜色跟酒馆当前美化走。

## 安装

1. 在酒馆扩展里用 Git 安装：`https://github.com/Nancyindaeyo/preset-ball`
2. 或把本仓库放到 `public/scripts/extensions/third-party/preset-ball`
3. 启用扩展。右下角会出现圆球。

需要当前加载的是 Chat Completion 预设（蛾摩拉 2.6 最完整）。快捷包按条目名匹配；换别的预设时方案快照仍可用，出厂快捷找不到的条目会跳过并提示。

## 开发

```bash
pnpm install
pnpm build
pnpm watch
```

产物在 `dist/`。酒馆从 `manifest.json` 的 `js` 加载。

## 用法（给第一次用的人）

1. 调好开关，点「把现在存成方案」，起名。
2. 点方案名字 = 套用。点「改」= 编辑每一条，可「只保存」或「保存并套用」。
3. 点「绑」= 这个聊天下次打开自动套用这份方案。没绑的聊天不会被改。
4. 顶部红字是冲突提示（开了两条互斥思维链、开了 NSFW 却关着接收器等）。
5. NSFW 规则可以改：不想关 NSFW 时自动打开「防止发情」，进规则把「关闭时打开」里那条拿掉即可。
6. 世界书：先「加入一本」，之后点一下挂全局，再点摘掉。方案里可选用「套用时同步世界书」，默认关。
